# CCL

Новая платформа персонажей WSGuild для D&D 5.5e/SRD 5.2.1.

Старый проект `ccl` не является зависимостью CCL2 и используется только как источник требований к интерфейсу и поведению.

## Состав проекта

```text
apps/
  characters/       кабинет, конструктор и менеджер персонажей
  api/              авторизация, MongoDB, публикация контента

packages/
  content-schema/   канонические типы и JSON Schema
  rules-engine/     чистое детерминированное расчётное ядро
  content-tools/    импорт, экспорт, упаковка и миграции
  ui/               общая дизайн-система
  i18n/             локализация технического интерфейса

schemas/            переносимые JSON Schema
examples/           проверочные пакеты и персонажи
docs/               архитектура и решения
```

Визуальный редактор «Кузница» развивается в отдельном соседнем репозитории `forge`. Оба проекта используют версионированный канонический JSON-контракт; копировать бизнес-логику между ними не нужно.

## Принципы

- логика никогда не зависит от переведённых названий;
- Excel, Кузница, MongoDB и VTT используют один канонический JSON;
- пользовательский код и Excel-макросы не исполняются;
- персонаж хранит исходные решения, а производные значения пересчитываются;
- опубликованные версии контент-пакетов неизменяемы;
- мобильные сценарии проектируются одновременно с десктопными.

## Проверки первого этапа

Нужны Node.js 22.18+ и pnpm. Ajv проверяет схемы по JSON Schema Draft 2020-12, а математическое ядро использует встроенный test runner Node.js.

```powershell
pnpm install
pnpm test
```
