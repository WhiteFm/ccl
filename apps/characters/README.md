# WSGuild Character Vault

Статическое React-приложение конструктора и менеджера персонажей D&D 5.5e.

## Разработка

```bash
pnpm dev
pnpm build
pnpm test
```

Сборка создаётся в `dist/`. GitHub Actions автоматически публикует её в GitHub Pages после отправки изменений в ветку `main`.

Публичный адрес: <https://ccl.wsguild.net>

Текущая демонстрационная версия хранит сессию, черновик и персонажей в локальном хранилище браузера. Серверная авторизация и MongoDB будут подключаться через отдельный API.
