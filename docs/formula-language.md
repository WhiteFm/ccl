# Безопасный язык формул

Формулы контента — это данные, а не JavaScript. Ядро разбирает ограниченный язык собственным парсером и никогда не вызывает `eval` или `Function`.

## Операторы

- арифметика: `+`, `-`, `*`, `/`, `%`;
- сравнения: `>`, `>=`, `<`, `<=`, `==`, `!=`;
- логика: `!`, `&&`, `||`;
- скобки задают порядок вычисления.

Булевы и числовые значения не приводятся друг к другу автоматически. Деление на ноль, неизвестные функции, неверные аргументы и бесконечный результат считаются ошибками контента.

## Доступный контекст

| Функция | Результат |
|---|---|
| `character_level()` | общий уровень персонажа |
| `class_level("dnd.class.fighter")` | уровень конкретного класса или `0` |
| `ability_score("str")` | итоговое значение характеристики |
| `ability_modifier("str")` | модификатор характеристики |
| `proficiency_bonus()` | бонус мастерства |
| `min(...)`, `max(...)` | минимум или максимум |
| `floor(x)`, `ceil(x)`, `abs(x)` | безопасные числовые операции |

Пример числовой формулы:

```text
proficiency_bonus() + ability_modifier("wis")
```

Пример требования для мультиклассирования:

```text
ability_score("str") >= 13 || ability_score("dex") >= 13
```

Расширять язык следует только версионируемыми функциями. Текст на русском или английском в формулах не используется: ссылки опираются на стабильные ID.
