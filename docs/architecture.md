# Архитектура CCL2

## Границы системы

CCL2 состоит из трёх независимо развёртываемых приложений и общих пакетов.

### Characters

- регистрация по email и паролю;
- три слота через entitlement пользователя;
- черновики конструктора первого уровня;
- менеджер готового персонажа;
- повышение уровня и мультиклассирование;
- установка homebrew-пакетов;
- экспорт переносимого персонажа.

### Forge

- локальные проекты в IndexedDB;
- визуальное создание официального и homebrew-контента;
- RU/EN и будущие локализации;
- безопасные формулы, эффекты, требования и выборы;
- JSON рабочего проекта;
- публикационный пакет `.wsgpack`;
- административная публикация официального контента.

### API

- email/password авторизация;
- хранение пользователей, entitlements, персонажей и черновиков;
- MongoDB как runtime-хранилище нормализованного контента;
- неизменяемые версии опубликованных пакетов;
- проверка персонажа серверным экземпляром общего rules engine;
- аудит, миграции и контроль одновременного редактирования через `revision`.

## Поток контента

```text
Кузница ─┐
         ├─> Canonical JSON ─> Validation ─> MongoDB ─> Characters/VTT
Excel ───┘                         │
                                  └─> package manifest + attribution
```

Кузница является полноценным редактором. Excel остаётся необязательным массовым импортом и экспортом.

## Поток расчёта персонажа

```text
Сохранённые решения
  -> разрешение ссылок на версии контент-пакетов
  -> grants и choices
  -> требования и конфликты
  -> нормализованный список эффектов
  -> граф зависимостей
  -> derived snapshot
  -> calculation trace
```

Производные значения могут кешироваться, но не являются источником истины.

## Контент-пакеты

Пакет содержит:

- уникальное namespace;
- правила и версию схемы;
- источник и лицензию;
- список зависимостей;
- технические сущности;
- локализации;
- индекс ресурсов;
- политику переносимости.

Официальные namespace могут публиковать только пользователи с административным правом. Homebrew не может переопределять официальный ID.

## Безопасность формул

Формулы разбираются собственным парсером. Запрещены:

- JavaScript и `eval`;
- доступ к объектам и свойствам;
- произвольные имена функций;
- сетевые и файловые операции;
- Excel-макросы.

Доступны только арифметика и белый список функций расчётного контекста.

## Сброс сборки персонажа

Полная перестройка сохраняет только:

- имя;
- фотографию;
- ручное описание.

Остальное создаётся заново с первого уровня. Перед транзакцией API сохраняет технический recovery snapshot.
