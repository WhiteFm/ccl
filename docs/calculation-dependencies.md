# Граф расчётных зависимостей

Ниже зафиксирован первоначальный порядок. Каждая строка в будущем станет отдельным вычислительным узлом с trace.

| Узел | Зависит от | Правило |
|---|---|---|
| Общий уровень | история уровней | количество записей уровня |
| Уровень класса | история уровней | количество уровней выбранного класса |
| Бонус мастерства | общий уровень | таблица ruleset |
| Базовые характеристики | метод генерации | Point Buy или шесть назначенных бросков |
| Итоговая характеристика | база, фон, черты, предметы | эффекты, затем ограничения |
| Модификатор | итоговая характеристика | `floor((score - 10) / 2)` |
| Спасбросок | модификатор, владение, PB, эффекты | один уровень владения, без двойного сложения |
| Навык | выбранная характеристика, владение, PB | характеристика по умолчанию может быть заменена контекстом |
| Пассивная проверка | модификатор проверки | базовое значение ruleset + модификаторы |
| Максимум HP | первый класс, уровни, CON, эффекты | первый уровень отдельно от следующих |
| Кости хитов | уровни классов | отдельные пулы по типу кости |
| КЗ | доступные формулы, броня, щит, эффекты | выбирается одна базовая формула, бонусы применяются отдельно |
| Инициатива | DEX, PB-эффекты, прочие эффекты | детерминированная сумма источников |
| Скорости | вид, эффекты, экипировка, состояния | отдельные типы движения |
| Чувства | вид, класс, эффекты | максимум/добавление задаётся stacking rule |
| Грузоподъёмность | STR, размер, эффекты | таблица ruleset |
| Толчок/подъём | грузоподъёмность | множитель ruleset |
| Уровень заклинателя | уровни классов | коэффициент и округление каждого класса |
| Ячейки заклинаний | уровень заклинателя, Pact Magic, эффекты | общая таблица и отдельные ресурсы |
| Сл спасброска заклинаний | PB, характеристика заклинателя | базовое значение + PB + модификатор |
| Атака заклинанием | PB, характеристика заклинателя | PB + модификатор |
| Атака оружием | профиль оружия, характеристика, владение | структурированные свойства, не текст |
| Урон оружием | кости, характеристика, стили, эффекты | trace каждой добавки |
| Сопротивления | grants, предметы, состояния | уникальные claims с источниками |
| Активные ресурсы | формула максимума, траты, восстановление | отдельное состояние использования |

## Порядок применения эффектов

1. базовые значения;
2. альтернативные формулы и `replace`;
3. аддитивные изменения;
4. множители;
5. минимумы и максимумы;
6. временные состояния;
7. формирование trace и предупреждений.

Конкретная сущность может переопределить порядок через `priority`, но не может исполнять произвольный код.
