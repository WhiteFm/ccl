# Каноническая модель контента

## Общие поля сущности

Каждая сущность имеет стабильный технический ID и не использует отображаемое имя в ссылках или формулах.

```text
id
entityType
rulesetId
sourceId
sourceVersion
licenseId
status
tags
deprecatedBy
```

## Локализация

Канонический JSON хранит переводы отдельно:

```json
{
  "localizations": {
    "ru": {
      "srd52.feature.example": {
        "name": "Название",
        "description": "Описание"
      }
    },
    "en": {
      "srd52.feature.example": {
        "name": "Name",
        "description": "Description"
      }
    }
  }
}
```

Для Excel те же данные представляются листами с суффиксами `_ru`, `_en` и далее. Технические поля остаются без языкового суффикса.

## Основные типы

- `ruleset`
- `reference`
- `species`
- `class`
- `subclass`
- `background`
- `feat`
- `feature`
- `spell`
- `item`
- `reference` с категорией `language`, `tool`, `condition`, `damage_type` и другими справочниками

## Источники и лицензии

Каждая сущность ссылается на источник. Пакет задаёт:

- текст атрибуции;
- вид лицензии;
- разрешение встраивания данных в экспорт персонажа;
- разрешение публикации производных пакетов;
- необходимость entitlement.

Это позволяет использовать SRD CC-BY и будущий лицензированный контент с разными правилами переноса.

## Эффекты

Эффект описывает одно атомарное механическое изменение. Несколько эффектов составляют умение, предмет или заклинание.

```text
target       combat.initiative
operation    add
value        proficiency_bonus()
activation   always_on
stacking     sum
priority     100
```

Нельзя извлекать механику из описания регулярными выражениями.

## Три типа умений

| Пользовательское название | Технический тип | Поведение |
|---|---|---|
| Единоразовое | `always_on` | всегда участвует в расчёте |
| Пассивное | `manual_unlimited` | применение объявляет игрок, лимита нет |
| Активное | `limited_use` | использует ресурс и восстановление |

## Версии

Опубликованная версия пакета неизменяема. Изменение создаёт новую версию. Персонаж хранит точные версии зависимостей и обновляется только через миграцию.
